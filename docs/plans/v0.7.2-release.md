# v0.7.2 release

Beads issue `k8s-device-plugin-rs-release-v0-7-2-g4k9` tracks this release.
The maintainer approved a patch release from reviewed main `45d538b`.

## Scope and compatibility

The shared release ships the panic and ownership hardening, Prost 0.14.6, the
DRA `h2` compatibility snapshot `v0.4.21+20261125`, and the dependency fixes
for [RUSTSEC-2026-0600](https://rustsec.org/advisories/RUSTSEC-2026-0600.html)
and [RUSTSEC-2026-0592](https://rustsec.org/advisories/RUSTSEC-2026-0592.html).
The latter updates `url` in the metrics example's dependency chain.

DRA now requires `kube` 5.2. An independent consumer resolved `kube = "5.0"`
to 5.2.0. Consumers with an exact pin below 5.2 must update it. The supported
OpenAPI schemas are Kubernetes 1.36 and 1.37.

## Publication evidence

- A clean main checkout with kubelet submodule `98912ce841e56c346b0e9a086eee5ee6c2764832`
  passed `mise run --jobs 1 release-preflight` on native arm64. The run passed
  251 workspace tests, 30 matrix tests, five profile-configuration tests,
  14 multi-node orchestration tests, strict Clippy, formatting, and independent
  consumer checks. The reviewed source also passed both schemas' strict
  Clippy, all-target tests, doctests, and rustdoc, plus the three protocol
  feature builds without external `protoc`.
- The explicit preview selected 0.7.2 and checked four documentation replacements.
  The version transaction pushed source commit
  `1dbd92697bc84bdfba55eaa779b027ebe993c11d` and annotated tag object
  `655e0071e3a95c7113100ef9b0dc3a10f6499b3e`. Before publication, remote
  main and the peeled tag both pointed to that clean checkout.
- The separate `cargo release publish` invocation used `release-publish.toml`,
  verified the package builds, and uploaded all eight public crates. Independent
  `cargo info` downloads into a fresh cache matched the source commit in all eight
  `.cargo_vcs_info.json` records. The protocol archive includes both DRA health
  schemas, and the DRA archive requires `kube` 5.2. The example stays unpublished.
- [GitHub CI on the tagged source](https://github.com/rkubectl/k8s-device-plugin-rs/actions/runs/45835381312)
  passed all 14 jobs. The [GitHub release](https://github.com/rkubectl/k8s-device-plugin-rs/releases/tag/v0.7.2)
  and [facade crate](https://crates.io/crates/k8s-device-plugin/0.7.2) went live
  on 2026-11-26.
